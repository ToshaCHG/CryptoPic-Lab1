# CryptoPic - Лабораторная работа №1

## Описание
В данной работе реализованы и сравнены три метода шифрования изображений:
1. Потоковый XOR с генератором xorshift32.
2. AES-256 в режиме ECB.
3. AES-256 в режиме CBC (со случайным IV).

## Зависимости
Для работы скрипта требуются следующие библиотеки Python:
* numpy
* pillow
* pycryptodome
* matplotlib

## Установка зависимостей
Выполните в терминале или в ячейке Colab:
!pip install numpy pillow pycryptodome matplotlib

## Запуск
1. Загрузите файл `src/lab1.ipynb` в Google Colab или Jupyter Notebook.
2. Убедитесь, что исходные изображения (например, `gradient.jpg`) находятся в корневой директории.
3. Запустите все ячейки кода по порядку.

## Параметры шифрования
По умолчанию в коде заданы:
* `KEY = "MySKey123"` (секретный ключ)
* IV для CBC генерируется случайно с помощью `os.urandom(16)` при каждом запуске.

## Структура проекта
* `src/` — исходный код (Jupyter Notebook).
* `imgs/` — исходные изображения.
* `results/` — метрики (`metrics.csv`), графики (`histograms.png`), зашифрованные данные (`*.bin`, `*.png`) и метаданные (`meta.json`).
